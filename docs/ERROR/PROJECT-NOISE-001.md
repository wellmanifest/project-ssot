# PROJECT-NOISE-001

## Meaning

Analyzer output was treated as debt or as project identity.

## Cause

code2llm TOON, `map.toon.yaml`, or redup was listed as `role=authority` or
carried `purpose` / `home` facts, or
`analyzerTreatAsDebtUntilInterview` is true.

## Resolution

Keep analyzer sources as `role=evidence` with empty identity facts. Run
the interview. Dual submodule checkouts and generated docs are usually not
description debt (see wellmanifest/ssot).
